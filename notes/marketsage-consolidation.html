Consolidating 11 Finance Prototypes into MarketSage Unified

Shipping prototypes is easy; retiring 11 overlapping tools into one zero-duplication, tested platform is where software engineering actually starts.

1. The problem: prototype sprawl

Over several months of building investing tools, I had accumulated 11 separate local apps and 8 GitHub repositories: a 100-bagger screener, an ETF analyzer, a mutual fund analyzer, a 10-guru stock screener, a DCF/dividend calculator, a multi-source SEC EDGAR fetcher, and Excel export notebooks. Each one solved a real question — and each duplicated market-data fetching, caching, and UI boilerplate.

To answer one research question ("Does this stock pass Buffett/Lynch quality screens, how does its 5-year FCF DCF look, and what do recent 10-K risks say?"), I was jumping across four apps.

2. Key architectural decisions

  • Pure-Python core/ decoupled from UI: Every domain module — data_engine.py, 45 strategies across 4 asset classes, technicals.py, dividends.py, backtester.py, portfolio.py (VaR/CVaR/Sortino/stress tests), and ai_research.py — runs headlessly with zero Streamlit imports, making unit testing fast and deterministic.
  • Resilient 4-source fallback + 24h SQLite cache: Free financial APIs rate-limit aggressively. A configurable chain (Alpha Vantage → Twelve Data → yfinance + SEC EDGAR) backed by a single SQLite database with per-source 24-hour TTL and daily quota tracking keeps the app responsive even when a provider throttles.
  • Deterministic offline quant fallback for AI research: The AI synthesis layer supports Claude, Gemini and OpenAI — and when no LLM key is configured (or an API fails), it degrades gracefully to a structured deterministic quant brief rather than crashing.
  • Clean boundary with Nigerian equities: Instead of forcing Nigerian Exchange (NGX) feeds into US/global schemas, NGX stayed dedicated to its own CI-driven Cloudflare Pages pipeline (ngx.leyesapps.com).

3. Measured outcome

Before vs. After Consolidation

11 local folders & 8 legacy GitHub repos archived cleanly with redirect notices → 1 modular codebase with 45 investment models, 9 Streamlit dashboards, styled multi-sheet Excel exports, 33 automated pytest tests running in GitHub Actions CI, and a Cloudflare Worker custom domain at marketsage.leyesapps.com.
